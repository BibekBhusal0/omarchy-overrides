# Omarchy Overrides

Personal Linux desktop configuration overrides for [Omarchy](https://github.com/basecamp/omarchy). Inspired by [typecraft](https://www.youtube.com/watch?v=d23jFJmcaMI)

## Installation

```bash
git clone https://github.com/bibekbhusal0/omarchy-overrides ~/Code/omarchy-overrides
chmod +x ~/Code/omarchy-overrides/**/*.sh ~/Code/omarchy-overrides/*.sh
~/Code/omarchy-overrides/index.sh
```
